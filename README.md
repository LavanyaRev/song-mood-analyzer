## Features

- User signup and login with password hashing (BCrypt)
- CRUD operations for playlists, songs, favorites, and mood history
- REST API endpoints for frontend integration
- Audio analysis utilities for detecting song mood
- Secure endpoints with Spring Security

---

## Tech Stack

- Java 17
- Spring Boot 3.4
- Spring Security
- JPA / Hibernate
- MySQL
- Lombok
- Maven
